# Sinema

Versões para instalar do Sinema, a app de Android TV. O código é privado; aqui ficam só os ficheiros de instalação.

**Última versão:** 1.6.4

**Instalar numa Android TV / Google TV / Nvidia Shield**

1. Na TV, instale a app **Downloader** (Play Store).
2. Em Definições › Apps › Downloader, autorize a instalação de apps desconhecidas.
3. No Downloader, escreva o endereço:
   `https://github.com/lewaluigi/Sinema-releases/raw/main/Sinema.apk`
4. Instale. Depois, o Sinema atualiza-se sozinho a partir daqui.

**Instalar no Windows**

Descarregue e corra o instalador: `https://github.com/lewaluigi/Sinema-releases/releases/latest/download/Sinema-Setup.exe`
(inclui o leitor de vídeo). Se o Windows avisar que não conhece a app, escolha "Mais informações" e "Executar assim mesmo".
